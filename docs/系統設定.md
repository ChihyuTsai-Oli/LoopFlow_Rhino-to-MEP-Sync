## 測試策略

分兩層，先寫不需要 Rhino 的那層。

**不需要 Rhino（`tests/`，用系統 Python 直接跑）**

涵蓋任何不碰 `Rhino`／`scriptcontext` 的邏輯：

- 單位換算（Rhino 值 ↔ 公尺，來回一致）。
- GlobalId 由 GUID 壓縮的結果穩定且長度 22。
- 圖層路徑排除記號的比對規則。
- 物件依底部 Z 歸屬樓層的判斷（給定樓層表與高度，算出應屬哪層）。
- `config.json` 讀寫與未知 `schema_version` 拒絕。
- 用 IfcOpenShell 直接開 `fixtures/` 的 IFC 做結構檢查，不需要 Rhino。

前提是把這些邏輯放在不 import Rhino 的模組裡。寫產品碼時要保持這個分界。

在 repo 根目錄執行：`python -m unittest discover -s tests -t .`

**需要 Rhino（人工）**

幾何轉換、圖層建立、對話框、發布流程。這層不做自動化，靠隔離 Rhino 實機驗證與 `開發任務與路徑.md` 的檢查清單。

**fixtures**

`fixtures/spike/` 是針刺產物。正式測檔日後放 `fixtures/`，至少要有：一個 R2M 自己寫的建築殼、一個 Archicad 出的 MEP、一個 Revit 出的 MEP。Archicad 匯入建築殼已過；Archicad 真實 MEP 與 Revit 兩項仍待家中實機。**測試 BIM 暫以 Archicad 為準。**

## yak 打包中的 vendor 輪子

IfcOpenShell 解壓後 `_ifcopenshell_wrapper.pyd` 單檔約 55 MB，是打包時最大的變數。

- 輪子解壓後的內容放套件內固定子目錄（暫定 `vendor/py39/`），執行時插入 `sys.path`。
- **不**裝進 `~\.rhinocode\py39-rh8\lib\site-packages`，避免污染使用者環境、也避免與其他外掛版本打架。
- `.vendor/` 只是開發期快取，不進 Git；日後的打包腳本要能從輪子重建 `vendor/py39/`。
- 全部打進 yak（ED-21）。打包前查 Package Manager 體積上限與 LGPL。未做依賴盤點與實包驗證前**不裁切** `ifcopenshell/api/`。
- LGPL 要求：IfcOpenShell 以獨立函式庫形式隨附，授權文字一併打包。
- **未驗證**：Rhino Package Manager 對套件體積的上限。打包前必須先查。

## 換機：重建 `.vendor/`

`.vendor/` 約 125 MB，已 gitignore，**不隨 Git 走**。換電腦後要跑針刺腳本或日後的產品碼，必須先在本機重建一次。

必須用 Rhino 自己的 Python 3.9（`%USERPROFILE%\.rhinocode\py39-rh8\python.exe`），不要用系統 Python。

```powershell
cd <repo>
$py = "$env:USERPROFILE\.rhinocode\py39-rh8\python.exe"
# --no-deps 很重要：不加會一起抓 shapely／lark／numpy，我們都不需要
& $py -m pip download "ifcopenshell==0.8.4.post1" typing_extensions --no-deps `
    --only-binary=:all: --python-version 39 --platform win_amd64 -d .vendor\wheels
# Expand-Archive 不吃 .whl，要先改副檔名
Get-ChildItem .vendor\wheels\*.whl | ForEach-Object {
    $zip = $_.FullName -replace '\.whl$', '.zip'
    Copy-Item $_.FullName $zip -Force
    Expand-Archive $zip -DestinationPath .vendor\py39 -Force
}
```

完成後 `.vendor\py39\` 應有 `ifcopenshell\`、`ifcopenshell-0.8.4.post1.dist-info\`、`typing_extensions.py` 與其 dist-info。驗證：在 Rhino ScriptEditor 把 `.vendor\py39` 插入 `sys.path` 後 `import ifcopenshell` 不報錯。

`ifcopenshell` 在裸 Python 3.9 會因為缺 numpy 而 import 失敗；Rhino 內建 numpy，所以**要在 Rhino 裡驗證**，不要在命令列。
