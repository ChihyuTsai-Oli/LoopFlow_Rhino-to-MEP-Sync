# LoopFlow R2M — 工作流程

本文件是主操作順序與失敗停點的權威來源。決策過程見 `前期規劃/資料生態決策表.md`；若衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models →（BIM 畫管）→ Inbound 轉外參 → 人改建築 → 再 Models。**

完整一圈：

1. Rhino 匯出建築模型 IFC。
2. BIM 作業，匯出 MEP 管線 IFC。
3. Rhino 把該 IFC 轉成 `.3dm`，當 **Worksession 外參**，對照著調整建築模型。
4. 再匯出建築 IFC。

沒有相機／燈光／即時 LiveLink。BIM 端無 LoopFlow 外掛。

開發期把 `docs/rhino指令.md` 的那一行貼到指令列（`_-ScriptEditor _Run`）。正式 yak 工具列尚未規劃裝包。

## 使用情境

| 情境 | Rhino | BIM | 檔 | 行為 |
|---|---|---|---|---|
| 建築殼 | `RMModels`（暫定） | 連結／參考 IFC | `models/R2M.ifc` | 只出選取圖層子樹的建築殼 |
| 管線外參 | `RMInbound`（暫定） | 內建匯出 IFC | 使用者手動另存的 `.3dm` | 只在目前文件建幾何；另存與掛載都手動 |
| Health | `RMOpen`（暫定） | — | 設定根 | 英文摘要；開 Config／models。Open Docs 目前開本機 `docs/`（入口 `docs/README.md`）；合入後有穩定 GitHub 頁再改開該 URL |

不要把外參幾何拿去出圖或當 Tag 來源。

## 開案

1. 開啟**已存檔** `.3dm`（未存檔則發布停）。
2. `RMOpen`：英文對話框開設定根與 last-good 摘要。Open Docs 目前開本機 `docs/`（入口 `docs/README.md`）；合入後有穩定 GitHub 頁再改開該 URL。
3. Revit／Archicad：連結 `R2M.ifc`，不要當原生檔來回轉。

## 樓層

Models 之前必須先有 **R2M 高程框**，由 `RMStorey` 登記。沒有就擋住，不發布。

### 畫框

自己畫封閉曲線，**一個樓層一個框，畫在該樓層自己的高度上**。框只要是水平的平面封閉曲線即可，形狀不拘。

- **框必須比外牆再大一圈。** 貼齊邊的物件會被 RMModels 擋住；這與 LoopFlow「共邊可」不同。
- 臨時編輯的物件移到框外即可（例如 x+1000），不必換圖層；同層框外件會被跳過。未勾選圖層不檢查。
- **RF 一定要畫（整棟模式）。** 屋頂板、女兒牆都掛在 RF。只畫其中幾層時不要硬找 RF，改走非整棟模式。
- **有屋凸就在 RF 上面再畫框**（機房、水塔、樓梯間），會自動編成 R2F、R3F。
- **沒有屋凸就不用多畫任何東西。** 最高層沒有上界，比它高的物件一律掛它。
- 地下室就畫在 1F 下面，會自動編成 B1、B2（由近而遠）。

### 登記

執行 `RMStorey`，選框前會先彈窗確認框必須閉合、水平、且嚴格大於要發布的物件。先選全部框，再彈窗選 **WholeBuilding** 或 **PartialStoreys**（不要在指令列按 Enter 選模式）。

**整棟（WholeBuilding）**

1. 選取全部樓層框 → Enter
2. 選取 1F 框 → Enter
3. 彈窗輸入 1F 高程（Rhino 文件單位，公分檔就填公分）→ Enter
4. 選取 RF 框 → Enter

其餘樓層的高程由各框自身的 Z 推算（`1F 高程 + 框的 Z 差`），名稱依序自動編 B1／1F／2F／RF／R2F。

**只做其中幾層（PartialStoreys）**

模型不是整棟時用這個，例如整棟 20 層但只畫 5F，或只畫 5F+6F。**不要**硬找 1F、RF，也**不要**補空樓層進 IFC。

1. 選取模型裡實際有的樓層框 → Enter
2. 點其中一層當基準 → Enter
3. 彈窗輸入該層名稱（例如 `5F`）→ Enter
4. 彈窗輸入該層 FL（例如 `1600`）→ Enter

其餘依框的高低連續編號（5F 上面是 6F、7F；低於 1F 是 B1）。非整棟不產生 RF／R2F。

兩種模式都會把框搬到圖層 `R2M::Storey`，並寫入 UserText `R2M_StoreyName`（樓層名）與 `R2M_FL`（FL 結構面高程）。

### 修改

- **改樓高**：移動框到新的高度，重跑 `RMStorey`。
- **改樓層名**：可以直接改 `R2M_StoreyName`，但**重跑 `RMStorey` 會整批覆寫回自動名稱**。
- **不要手改 `R2M_FL`。** 它由 `RMStorey` 寫入；`RMModels` 發布時會用框的 Z **差**反算驗證，對不上就擋住並要求重跑 `RMStorey`。FL 可以是建築標高，不必等於框在模型裡的 Z。

### 基準

- 高程用 **FL 結構面**。**不要填 FFL 完成面。** LoopFlow 那邊記的是 FFL，兩者差一層面材厚度，約 3 到 5 公分，正好落在天花與管線的衝突判斷範圍內，混用會誤判。
- LoopFlow 與 R2M 是兩個獨立來源，程式不互相讀取、不自動比對。改樓高時兩邊都要改，由人工確認。

## Models

英文介面，六步（開發期一個對話框一次問完；Eto 不可用時改指令列）：

1. **確認樓層**：列出目前 `R2M::Storey` 高程框、FL 與框的 Z，並提示只有嚴格在框內的物件會發布。缺少、名稱或 FL 重複、或層高差與框的 Z 差對不上則擋住。掛層用框的 Z；IFC 樓層 `ObjectPlacement` 與 `Elevation` 寫 FL，網面 Z 相對框高。
2. **排除記號**（預設 `//`；空白＝不排除）。圖層路徑含此文字者不匯出。
3. **最末端圖層**：只列出沒有子層的圖層；可捲動。**Select All**／**Select None**。第一次全不勾。面板依這個 `.3dm` 檔名分開記；同一資料夾的整棟／單層不會互相蓋掉。
4. **IFC 類型**：勾起來才匯出。下拉**預設** `IfcPlate`。天花選 `IfcCovering`。牆／板／柱／樑／樓梯請改成對應類型。舊存的 Proxy 會顯示成 Plate。要藏請取消勾選。父層不繼承類型。發布前再列出圖層→類型對照。
5. **幾何類別勾選**：顯示數量；Point／Curve 預設不勾，其餘預設勾。記住這個檔上次的勾選。
6. **網格密度**：粗／中／細，預設中。寫進 config／log。
7. 底部按鈕（Cancel 左邊）：**Save Config** 立刻寫這個檔的面板，對話框不關；**Load Config** 讀回這個檔上次寫入的紀錄（無檔案挑選）。沒有紀錄就提示。**Publish** 會先寫面板再出 IFC，避免 IFC 被 Dropbox 鎖住時勾選全丟。

其後：

- 勾選圖層上，範圍盒必須嚴格落在該層高程框內才匯出；碰到框線擋住；框外同層跳過；低於最低層跳過（指令列會列出 skipped below 件數）。掛層看範圍盒**底部 Z**。
- **跨層物件（非整棟模式；公開說明見 `docs/USER_GUIDE_zh-TW.md`／`COMMANDS_zh-TW.md`）**：`RMStorey` 選 PartialStoreys 時，幾何的底部或頂部只要超出目前已畫高程框的範圍，就要把那一層框也畫進去，Archicad 才顯示得完整。底部超出＝低於最低層會被跳過。頂部超出＝對方檔沒有那層標高，看起來會黏在下一層。整棟模式框已齊，不適用這條。不發明沒畫的樓層。家中單層實測：只畫 3F／4F 時跨到 2F 的牆消失；補 2F 框後 75→81 件、skipped below 7→0。
- **排除 Worksession 外參物件**（`IsReference`）。否則管線會被包回建築 IFC 送回 BIM，形成迴圈。
- 幾何轉三角網面寫成 `IfcTriangulatedFaceSet`；長度換成公尺；XY 不平移；Z 相對該層框。
- 寫入 pending IFC → 驗證 → atomic 成 `models/R2M.ifc`；失敗不碰 last-good。驗證項目見 `資料契約.md`。
- 來源文件狀態還原（含 `doc.Modified`）。
- 發布前列出**各層件數與最高物件 Z**。最高層無上界，這份摘要是用來肉眼確認沒有物件飄到天上；低於最低層的物件跳過，指令列會列出跳過件數。
- 過半物件是 `IfcBuildingElementProxy` 時指令列警告：Archicad 可能不顯示這些件，請改類型或取消勾選。
- 空範圍／取消任一步＝阻擋，不發布。
- 開發期從 ScriptEditor 跑時，每次會丟掉已載入的 `loopflow_r2m`，同一 Rhino 視窗重跑就會用磁碟上的新碼。

## Inbound（第一版全手動；公開說明見 `docs/USER_GUIDE_zh-TW.md`／`COMMANDS_zh-TW.md`）

BIM 只出 **3D 管線**（衝突段或勾選系統；不要整棟、不要 2D）。含保溫／外包絡為佳。Archicad 版本與精確匯出按鈕未記錄；下列用已決契約用語，不杜撰選單文案。

**Archicad（僅家中）**

1. **檔案 → 開啟**，把產品建築殼 IFC 當新檔（單層 2F／3F／4F 方便對天花）。不要 Merge、不要 Update 進範本。
2. 在該檔畫幾段 **3D** 風管或水管，跨越天花高度。
3. 內建 IFC 匯出：**IFC4**；只出 3D 管線；不要整棟建築、不要 2D、座標不要另做偏移。標高與樓層維持原樣。
4. 檔名標來源（Archicad）與日期。先放工作檔旁；之後拷進 repo `fixtures/`。產品程式不寫死 Dropbox 路徑。

**Rhino**

1. 開一個**空白 `.3dm`**，單位設成與工作檔相同。
2. 指令列貼 `docs/rhino指令.md` 的 **RMInbound** 那一行。選剛匯出的 IFC。指令會先顯示目前文件單位請你確認；建幾何前先統計候選件數，若 `inbound_count_warning` 已填且超過則警告並可取消；再把可建幾何建成鎖定網面，並顯示類別統計。物件名稱寫成 `IfcType:GlobalId`，依 IFC 類型分層（`R2M_Inbound::<類型>`）並在圖層上色。
3. **手動**另存成 `.3dm`（建議工作檔旁 `_LoopFlow_Config/loopflow_R2M/inbound/`，固定檔名）。
4. 回工作檔**手動**用 Worksession 掛上該 `.3dm`。

指令**不**寫檔、**不**另存、**不**掛載、**不**碰 `.rws`。隔離檔再跑；不要用 MCP 代跑 `RM*`。

外參更新：管線更新時重跑 Rhino 1 到 3 覆寫同一個 `.3dm`，再到 Worksession 管理員按 Refresh。固定檔名才能這樣更新。

要知道的事：

- 外參物件不能編輯，但可以抓點、可以當作圖依據。
- `.rws` 是個人檔，不存在 `.3dm` 裡，換電腦要重掛一次。這不是壞掉。
- `RMInbound` **不要求文件已存檔**；空白新檔本來就沒存過。
- **不**布林建築、不寫 Dictionary、不進出圖。
- 第一版**不做**碰撞檢查，也**不**把 BIM 衝突點畫成 Rhino Dot（待評估）。

人看著外參改原天花／牆／板，再跑 Models。

## BIM 端設定要點

這節是給對方工程師看的。公開草稿見 `docs/USER_GUIDE_zh-TW.md` 與 `docs/COMMANDS_zh-TW.md`。Rhino 端對應：

- **跨層物件（非整棟模式）**：`RMStorey` 選 PartialStoreys 時，底部或頂部超出已畫高程框就要多畫那一層框。不補空樓層、不改幾何。整棟模式不適用。
- **Archicad 收檔**：檔案 → 開啟 IFC 當新檔。不必刪 Story。
- **Archicad 出管 → Rhino**：見上一節 Inbound 逐步。

- **測試 BIM 暫以 Archicad 為準**（2026-09-21 起）。產品對口仍含 Revit，但 Revit 尚未測；未測前不要把 Revit 行為寫成已驗證。
- Archicad：家中已把 `fixtures/spike` 的 IFC 匯入，沒有問題。畫管、匯出真實 MEP IFC 仍待做。
- Revit：設定要點先照下列寫，等實機後再補正。

**收 Rhino 的建築 IFC**

- Revit（尚未測）：用「連結 IFC」，不要用「開啟」或「匯入」。連結才能在 Rhino 更新後重新載入。
- Archicad **標準流程：檔案 → 開啟**，把 IFC 當新檔。家中實測（2026-09-23）：整棟與單層樓層名、FL、幾何都對；**不必刪任何預設 Story，也不會出現 Ground Floor**。
- 不要用 Merge 收非整棟（會把 IFC 第 0 層對到 Ground Floor）。Update 進既有範本會留下刪不掉的 Ground Floor，不當標準。
- **不要**為了迎合 Merge／範本而在 IFC 裡補 0 m 空樓層（ED-32）。
- 天花選 `IfcCovering`。未改下拉寫成 `IfcPlate`。仍選 Proxy 的件 Archicad 常不顯示。
- 不要轉成原生元素再各自修改。Rhino 覆寫同一個 `R2M.ifc` 之後，對方要重新載入該連結。
- 建築殼是**參考**，不是給對方接手編輯的模型。設計變更一律回 Rhino 做。

**出 MEP 管線 IFC 給 Rhino**

逐步見上面 Inbound。重點：IFC4、只 3D 管線、不要整棟／2D、座標不偏移、含保溫較好。檔名標來源。Rhino 空白檔跑 `RMInbound`，手動另存再掛 Worksession。

## 失敗停點

| 情況 | 行為 |
|---|---|
| Models 時文件未存檔 | 停止 |
| 缺 R2M 高程框、名稱衝突、或最高層沒有頂部上界 | 停止並說明 |
| 空圖層／沒勾類別／取消 | 不發布 |
| 匯出圖層未指定 IFC 類型 | 寫成 `IfcPlate`，不擋住 |
| 目前文件單位與預期不符（Inbound） | 顯示單位請使用者確認；不自行換算 |
| IFC 寫入或驗證失敗 | 保留 last-good |
| 進來的檔沒有可建出幾何的實體 | 停止並說明 |
| IFC schema 不是 IFC4 或無法解析 | 停止並說明，不猜測 |
| 無法載入 IfcOpenShell | 停止並說明，不裝 VisualARQ 當默認後門（除非決策改口） |
