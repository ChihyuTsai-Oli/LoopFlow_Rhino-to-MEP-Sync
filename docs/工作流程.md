# LoopFlow R2M — 工作流程

本文件是主操作順序與失敗停點的權威來源。決策過程見 `前期規劃/資料生態決策表.md`；若衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models →（BIM 畫管）→ Inbound 轉外參 → 人改建築 → 再 Models。**

完整一圈：

1. Rhino 匯出建築模型 IFC。
2. BIM 作業，匯出 MEP 管線 IFC。
3. Rhino 把該 IFC 轉成 `.3dm`，當 **Worksession 外參**，對照著調整建築模型。
4. 再匯出建築 IFC。

沒有相機／燈光／即時 LiveLink。BIM 端無 LoopFlow 外掛。

開發期把 `docs/rhino指令.md` 的那一行貼到指令列（`_-ScriptEditor _Run`）。正式 yak 工具列尚未規劃裝包。

## 使用情境

| 情境 | Rhino | BIM | 檔 | 行為 |
|---|---|---|---|---|
| 建築殼 | `RMModels`（暫定） | 連結／參考 IFC | `models/R2M.ifc` | 只出選取圖層子樹的建築殼 |
| 管線外參 | `RMInbound`（暫定） | 內建匯出 IFC | 使用者手動另存的 `.3dm` | 只在目前文件建幾何；另存與掛載都手動 |
| Health | `RMOpen`（暫定） | — | 設定根 | 英文摘要；開 Config／models／Docs |

不要把外參幾何拿去出圖或當 Tag 來源。

## 開案

1. 開啟**已存檔** `.3dm`（未存檔則發布停）。
2. `RMOpen`：英文對話框開設定根與 last-good 摘要（細節可議）。
3. Revit／Archicad：連結 `R2M.ifc`，不要當原生檔來回轉。

## 樓層

Models 之前必須先有 **R2M 高程框**，由 `RMStorey` 登記。沒有就擋住，不發布。

### 畫框

自己畫封閉曲線，**一個樓層一個框，畫在該樓層自己的高度上**。框只要是水平的平面封閉曲線即可，形狀不拘。

- **RF 一定要畫。** 屋頂板、女兒牆都掛在 RF。
- **有屋凸就在 RF 上面再畫框**（機房、水塔、樓梯間），會自動編成 R2F、R3F。
- **沒有屋凸就不用多畫任何東西。** 最高層沒有上界，比它高的物件一律掛它。
- 地下室就畫在 1F 下面，會自動編成 B1、B2（由近而遠）。

### 登記

執行 `RMStorey`，四步：

1. 選取全部樓層框 → Enter
2. 選取 1F 框 → Enter
3. 彈窗輸入 1F 高程（Rhino 文件單位，公分檔就填公分）→ Enter
4. 選取 RF 框 → Enter

其餘樓層的高程由各框自身的 Z 推算（`1F 高程 + 框的 Z 差`），名稱依序自動編。框會被搬到圖層 `R2M::Storey`，並寫入 UserText `R2M_StoreyName`（樓層名）與 `R2M_FL`（FL 結構面高程）。

### 修改

- **改樓高**：移動框到新的高度，重跑 `RMStorey`。
- **改樓層名**：可以直接改 `R2M_StoreyName`，但**重跑 `RMStorey` 會整批覆寫回自動名稱**。
- **不要手改 `R2M_FL`。** 它由 `RMStorey` 寫入；`RMModels` 發布時會用框的 Z 反算驗證，對不上就擋住並要求重跑 `RMStorey`。

### 基準

- 高程用 **FL 結構面**。**不要填 FFL 完成面。** LoopFlow 那邊記的是 FFL，兩者差一層面材厚度，約 3 到 5 公分，正好落在天花與管線的衝突判斷範圍內，混用會誤判。
- LoopFlow 與 R2M 是兩個獨立來源，程式不互相讀取、不自動比對。改樓高時兩邊都要改，由人工確認。

## Models

英文介面，六步（開發期一個對話框一次問完；Eto 不可用時改指令列）：

1. **確認樓層**：列出目前 `R2M::Storey` 高程框與 FL。缺少、名稱或 FL 重複、或 FL 與框的 Z 對不上則擋住。
2. **排除記號**（預設 `//`；空白＝不排除）。圖層路徑含此文字者不匯出。
3. **階層圖層樹**選專案圖層（可捲動；含子層）。
4. **IFC 類型**：對每個實際匯出的圖層下拉選類型，顯示件數；記住上次成功選擇。新增、改名或失效對應必須重選，不默認 Proxy。父層選取不等於子層繼承類型。發布前再列出圖層→類型對照；同層會變成單一類型，混放牆／天花須先整理。
5. **幾何類別勾選**：顯示數量；Point／Curve 預設不勾，其餘預設勾。記住上次成功勾選。
6. **網格密度**：粗／中／細，預設中。寫進 config／log。

其後：

- 依明確物件 ID；隱藏／鎖定暫時顯示解鎖；**禁止 `_SelAll`**。
- **排除 Worksession 外參物件**（`IsReference`）。否則管線會被包回建築 IFC 送回 BIM，形成迴圈。
- 幾何轉三角網面寫成 `IfcTriangulatedFaceSet`；長度換成公尺；座標不平移。
- 寫入 pending IFC → 驗證 → atomic 成 `models/R2M.ifc`；失敗不碰 last-good。驗證項目見 `資料契約.md`。
- 來源文件狀態還原（含 `doc.Modified`）。
- 發布前列出**各層件數與最高物件 Z**。最高層無上界，這份摘要是用來肉眼確認沒有物件飄到天上；低於最低層的物件仍然擋住。
- 空範圍／取消任一步＝阻擋，不發布。

## Inbound（第一版全手動）

BIM 只出 **3D 管線**（衝突段或勾選系統；不要整棟、不要 2D）。含保溫／外包絡為佳。

Rhino 端四步，指令只做第 2 步：

1. 開一個**空白 `.3dm`**，單位設成與工作檔相同。
2. 跑 `RMInbound` 讀管線 IFC。指令會先顯示目前文件單位請你確認；建幾何前先統計候選件數，若 `inbound_count_warning` 已填且超過則警告並可取消；再把可建幾何建成網面，並顯示讀到的類別統計。物件名稱寫成 `IfcType:GlobalId`，依 IFC 類型分層（`R2M_Inbound::<類型>`）並在圖層上色。
3. **手動**另存成 `.3dm`（建議放工作檔旁 `_LoopFlow_Config/loopflow_R2M/inbound/`，並固定檔名）。
4. 回工作檔**手動**用 Worksession 掛上該 `.3dm`。

指令**不**寫檔、**不**另存、**不**掛載、**不**碰 `.rws`。

外參更新：管線更新時重跑 1 到 3 覆寫同一個 `.3dm`，再到 Worksession 管理員按 Refresh。固定檔名才能這樣更新。

要知道的事：

- 外參物件不能編輯，但可以抓點、可以當作圖依據。
- `.rws` 是個人檔，不存在 `.3dm` 裡，換電腦要重掛一次。這不是壞掉。
- `RMInbound` **不要求文件已存檔**；空白新檔本來就沒存過。
- **不**布林建築、不寫 Dictionary、不進出圖。

人看著外參改原天花／牆／板，再跑 Models。

## BIM 端設定要點

這節是給對方工程師看的，寫進日後使用說明。

- **測試 BIM 暫以 Archicad 為準**（2026-09-21 起）。產品對口仍含 Revit，但 Revit 尚未測；未測前不要把 Revit 行為寫成已驗證。
- Archicad：家中已把 `fixtures/spike` 的 IFC 匯入，沒有問題。畫管、匯出真實 MEP IFC 仍待做。
- Revit：設定要點先照下列寫，等實機後再補正。

**收 Rhino 的建築 IFC**

- Revit（尚未測）：用「連結 IFC」，不要用「開啟」或「匯入」。連結才能在 Rhino 更新後重新載入。
- Archicad（匯入測檔已過）：用「合併」或熱連結模組參考，不要轉成原生元素再各自修改。
- Rhino 覆寫同一個 `R2M.ifc` 之後，對方要在各自軟體重新載入該連結。
- 建築殼是**參考**，不是給對方接手編輯的模型。設計變更一律回 Rhino 做。

**出 MEP 管線 IFC 給 Rhino**

- 只出 3D 管線，最好只出衝突段或指定系統。不要整棟、不要 2D 圖面。
- 含保溫層或外包絡為佳，Rhino 端要看的是實際佔用空間。
- 座標不要另外偏移，與收到的建築 IFC 用同一組座標。
- 標高與樓層維持原樣，不要為了出檔重新編號。

## 失敗停點

| 情況 | 行為 |
|---|---|
| Models 時文件未存檔 | 停止 |
| 缺 R2M 高程框、名稱衝突、或最高層沒有頂部上界 | 停止並說明 |
| 空圖層／沒勾類別／取消 | 不發布 |
| 匯出圖層未指定 IFC 類型 | 停止並說明，不默認 Proxy |
| 目前文件單位與預期不符（Inbound） | 顯示單位請使用者確認；不自行換算 |
| IFC 寫入或驗證失敗 | 保留 last-good |
| 進來的檔沒有可建出幾何的實體 | 停止並說明 |
| IFC schema 不是 IFC4 或無法解析 | 停止並說明，不猜測 |
| 無法載入 IfcOpenShell | 停止並說明，不裝 VisualARQ 當默認後門（除非決策改口） |
