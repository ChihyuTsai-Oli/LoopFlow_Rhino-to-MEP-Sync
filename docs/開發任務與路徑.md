契約以 `資料契約.md` 為準；即時狀態只記 `重構進度.md`。

## 執行規則

- **能做就做、需確認再停。** AI 在已決契約與本檔範圍內直接推進文件、空殼、可自動驗證的實作並提交；僅在下列情況停下來問使用者——改已決 ED、凍結使用者可見名稱／檔名、破壞性操作、本機安裝正式 runtime、或與決策明顯衝突。
- 一次一個 repo／一台電腦／一個 AI。
- 文件與針刺腳本可在短期分支進行。產品指令從 `v1-development` 再開 `codex/v1-<scope>`。
- **可測：** Models 的消費＝BIM 能連結 IFC；Inbound 的消費＝Rhino 鎖定參考看得到。BIM 端不寫外掛。
- **測試 BIM 暫以 Archicad 為準**（2026-09-21 起）。產品對口仍是 Revit 與 Archicad；Revit 驗證延後，不從產品範圍拿掉。
- **Archicad 只有家中電腦。** 公司不能做 BIM 連結／匯出。Rhino 8 兩台都有。實作主線（C01／D01／單元測試）不等家中 Archicad 檔才開工。
- 前期規劃當原則；衝突先改決策表。
- 不把 LoopFlow 2.0／R2B／R2O 的相機燈光混進本產品。

## 公司日 Rhino 實機

**本輪（2026-09-22 換機後）公司不測 Archicad。** 若之後公司有空，隔離 slot 可測 `RMOpen`／`RMInbound`（spike 管線即可），不要動正在編輯的工作檔，不要用 MCP 代跑 `RM*`。R2M 切到 **`codex/v1-default-plate`**，不要停在 `main` 或 `v1-development`。

公司若要跑指令，先確認 `.vendor/`（見 `系統設定.md`「換機：重建 `.vendor/`」）。用 Rhino 的 Python 3.9。指令列貼上見 `rhino指令.md`。

**以下本輪不做**；僅供日後公司有空、且使用者要求時。

**1. 重建 `.vendor/`**（不進 Git；公司電腦沒有這份快取就跑不了指令）

步驟見 `系統設定.md`「換機：重建 `.vendor/`」。用 Rhino 的 Python 3.9，不要用系統 Python。

**2. `RMOpen`**

- 開新檔並存成例如 `r2m_test.3dm`（公分檔即可）。
- 把 `rhino指令.md` 的 **RMOpen** 那一行貼到指令列，Enter。
- 應出現英文摘要；可開 Config／models／Docs。未存檔應停止。

**3. `RMStorey`**

- 任意圖層畫三條水平封閉矩形，Z 分別為 0、300、600（公分檔）。框要比後面的牆再大一圈（例如 0 到 1200），不要貼齊外牆。
- 把 `rhino指令.md` 的 **RMStorey** 那一行貼到指令列。先確認說明窗 → 選全部三條 → Enter → 彈窗選 **WholeBuilding** → 點 Z=0 那條當 1F → Enter → 輸入 `0` → Enter → 點 Z=600 那條當 RF → Enter。
- 通過：三條被搬到 `R2M::Storey`，指令列列出 `1F FL=0`、`2F FL=300`、`RF FL=600`；屬性面板看得到 `R2M_StoreyName` 與 `R2M_FL`。
- 非整棟：另畫兩條框（Z=1600、1920），選 **PartialStoreys**，基準點低的那條、名稱 `5F`、高程 `1600`。應得到 `5F FL=1600`、`6F FL=1920`。
- 再測一次覆寫：把 RF 那條往上移 100，重跑整棟步驟，`RF` 應變成 `FL=700`。

**4. `RMModels`**

- 另圖層各畫一塊牆、一塊天花（底部約在 0 與 280），放在框**內側**、不要貼邊。
- 同層在 x+1000 再放一塊臨時牆。
- 把 `rhino指令.md` 的 **RMModels** 那一行貼到指令列。第一次圖層全不勾；勾牆／天花層，牆選 `IfcWall`、天花選 `IfcCovering`，其餘可當參考。確認類型對照後發布。
- **重點驗收**：指令跑完後，選取狀態必須與執行前相同（先前的全選是 `IsSelected` 漏括號造成，本批已修）。框內件發布成功，x+1000 那塊被跳過。把框縮到貼牆再跑一次應擋住。
- 通過：工作檔旁出現 `_LoopFlow_Config/loopflow_R2M/models/R2M.ifc`，來源檔選取／隱藏狀態還原。
- **把這份 `R2M.ifc` 帶回家**（Dropbox 或拷貝），家中 Archicad 要連的是產品產出，不只 spike。

**5. `RMInbound`**

- 再開一個**空白**新檔（這次可以先不存）。
- 把 `rhino指令.md` 的 **RMInbound** 那一行貼到指令列。確認單位後，選 `fixtures/spike/R2M_spike_pipe.ifc`。
- 通過：出現鎖定網面，圖層 `R2M_Inbound::IfcPipeSegment`，指令不另存、不掛 Worksession。

## B03 家中 BIM 驗證步驟

目的有兩個：確認 BIM 吃得下 R2M 的建築殼，以及**拿一份對方出的真實 MEP IFC 回來**。第二項比第一項重要，因為現在手上只有自己寫的管線測檔。

**測試暫以 Archicad 為準，且只能在家中做。** 下列步驟在家中 Archicad 做完；公司日跳過。Revit 同一套延後補測，不從產品對口拿掉。不擋 C01／D01 在兩台電腦繼續寫。

**收建築殼**

1. 用 `fixtures/spike/R2M_spike_shell_mesh.ifc`（三角網面版，產品實際會用的表示法）。不要只測 `R2M_spike_shell.ifc`，那是參數化量體，不代表產品行為。
2. Revit（尚未測）：新專案 → 插入 → 連結 IFC。Archicad：**開啟 IFC 當新檔**（標準；不必刪 Story）。不要 Merge／不要 Update 進範本。後續測試先走 Archicad。
3. 確認四件事：能開啟不報錯；量出來的尺寸對（牆 4 × 0.2 × 2.8 m，天花 4 × 4 m、底在 2.8 m）；元件落在原點附近；看得到 Level 1 樓層而不是全部散在同一層。
4. 記下對方把 `IfcCovering` 顯示成什麼類別、樓層名稱怎麼呈現。

**出 MEP 管線（僅家中 Archicad；公司日跳過）**

5. 用 **檔案 → 開啟** 把產品建築殼 IFC 當新檔（單層 2F／3F／4F 方便對天花）。不要 Merge／不要 Update 進範本。不必刪 Story。
6. 畫幾段 **3D** 風管或水管，跨越天花高度。不要只畫 2D。
7. 匯出 **IFC4**：只出 3D 管線；不要整棟建築、不要 2D、座標不偏移。標高與樓層維持原樣。Archicad 版本與精確按鈕未記錄。
8. 檔名標來源（Archicad）與日期。先放工作檔旁；之後拷進 `fixtures/`。

**回 Rhino 驗證**

9. 開空白 `.3dm`，單位與工作檔相同。貼 `docs/rhino指令.md` 的 **RMInbound**，選該 IFC。確認幾何完整、位置對、單位對。不要用 MCP 代跑 `RM*`。
10. **手動**另存 `.3dm`（建議 `_LoopFlow_Config/loopflow_R2M/inbound/`，固定檔名）。指令不寫檔。
11. 回工作檔**手動**掛 Worksession。確認外參可見、鎖定、能抓點。換機要重掛（`.rws` 不跟 `.3dm`）。
12. 對照天花看視覺碰撞即可。第一版不做碰撞檢查、不畫 Dot。

**要記錄的事**

- 元件數與讀取耗時（給 ED-20 的警告門檻）。
- 三角網面在 BIM 端的開啟速度（給 ED-15 的網格密度）。
- 對方軟體版本與 IFC 匯出設定。
