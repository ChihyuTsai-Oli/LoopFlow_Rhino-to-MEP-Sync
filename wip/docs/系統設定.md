# LoopFlow R2M — 系統設定

本文件是維護設定與現況結構的權威來源。實作範圍見 `實作總覽.md`；任務見 `開發任務與路徑.md`。

## Repo 與版本

| 項目 | 設定 |
|---|---|
| 穩定分支 | `main`（目前文件骨架） |
| 整合分支 | 寫程式時再建 `v1-development` |
| 短期工作分支 | `codex/v1-<scope>`（有程式後） |
| Runtime | Rhino 8 / CPython 3.9 / Windows |
| 對口 | Revit、Archicad（內建 IFC） |
| 交換 | 只 IFC |

## 工作資料夾

**`.3dm` 所在資料夾就是工作資料夾。** 未存檔則相關指令停止。

開發暫定：

- 設定與發布：`<3dm 資料夾>\_LoopFlow_Config\loopflow_R2M\`
- 建築殼：`models\R2M.ifc`
- 管線參考：`inbound\`
- log：`r2m.log`

Dropbox 測檔路徑見工作區根目錄 `工作檔路徑.md`。**R2M 測檔根目前待補**，未設環境變數前不要寫死公司或家中 Dropbox 絕對路徑。針刺用小型本機／既有測檔即可，不必先開新 Dropbox 夾。

## 介面語系

規劃與系列一致：正式 yak 一份、畫面英文 machine key、文件繁中為真相。本輪無介面碼。

## 依賴（規劃）

- IfcOpenShell：LGPL-3.0-or-later。可隨 yak 發行，須附授權、當獨立函式庫。針刺通過前不打進產品。
- 不把 VisualARQ／BEAM／Geometry Gym 當預設使用者前置，除非 B01 失敗後改口。

## 明確不做

- AutoCAD 2D 對口
- Revit／Archicad 外掛
- 自動套用降天花
- 把管線當 LoopFlow 物件
- 寫死單機 Dropbox 路徑
- 與 R2B／R2O 共用 runtime package
