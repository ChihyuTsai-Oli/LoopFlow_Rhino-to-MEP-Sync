# LoopFlow R2M — 系統設定

本文件是維護設定與現況結構的權威來源。實作範圍見 `實作總覽.md`；任務見 `開發任務與路徑.md`。

## Repo 與版本

| 項目 | 設定 |
|---|---|
| 穩定分支 | `main`（目前文件骨架） |

## 工作資料夾

**`.3dm` 所在資料夾就是工作資料夾。** 未存檔則相關指令停止。

開發暫定：

- 設定與發布：`<3dm 資料夾>\_LoopFlow_Config\loopflow_R2M\`
- 建築殼：`models\R2M.ifc`
- 管線參考：`inbound\`
- log：`r2m.log`

Dropbox 測檔路徑見工作區根目錄 `工作檔路徑.md`。**R2M 測檔根目前待補**，未設環境變數前不要寫死公司或家中 Dropbox 絕對路徑。針刺用小型本機／既有測檔即可，不必先開新 Dropbox 夾。

## 依賴

- **已決釘版：** IfcOpenShell `0.8.4.post1`、wheel `ifcopenshell-0.8.4.post1-py39-none-win_amd64.whl`。
- **額外純 Python：** `typing_extensions`（Rhino 內建環境沒有）。
- **Rhino 8 已有：** numpy（geom 頂點可用）。
- **不裝進** `~\.rhinocode\py39-rh8\lib\site-packages`。針刺與日後 yak 都用套件內目錄 + `sys.path`。
- 不把 VisualARQ／BEAM／Geometry Gym 當預設使用者前置。
- 第一版不依賴 shapely／lark（`ifcopenshell.api` 與 stream parser 才會要）。

## 明確不做

- AutoCAD 2D 對口
- Revit／Archicad 外掛
- 自動套用降天花
- 把管線當 LoopFlow 物件
- 寫死單機 Dropbox 路徑
- 與 R2B／R2O 共用 runtime package
