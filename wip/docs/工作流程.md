# LoopFlow R2M — 工作流程

本文件是主操作順序與失敗停點的權威來源。決策過程見 `前期規劃/資料生態決策表.md`；若衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models →（BIM 畫管）→ Inbound → 人改建築 → 再 Models。**

沒有相機／燈光／即時 LiveLink。BIM 端無 LoopFlow 外掛。

開發期 Rhino 用 ScriptEditor。正式 yak 工具列尚未規劃裝包。

## 使用情境

| 情境 | Rhino | BIM | 檔 | 行為 |
|---|---|---|---|---|
| 建築殼 | `RMModels`（暫定） | 連結／參考 IFC | `models/R2M.ifc` | 只出選取圖層子樹的建築殼 |
| 管線參考 | `RMInbound`（暫定） | 內建匯出 IFC | `inbound/` | 鎖定參考層；整批更新；不當建築 |
| Health | `RMOpen`（暫定） | — | 設定根 | 英文摘要；開 Config／models／inbound／Docs |

不要把 Inbound 幾何拿去出圖或當 Tag 來源。

## 開案

1. 開啟**已存檔** `.3dm`（未存檔則發布停）。
2. `RMOpen`：英文對話框開設定根與 last-good 摘要（細節可議）。
3. Revit／Archicad：連結 `R2M.ifc`，不要當原生檔來回轉。

## Models

對齊 R2B／R2O，三步（英文介面；細節可議）：

1. **排除記號**（預設 `//`；空白＝不排除）。圖層路徑含此文字者不匯出。
2. **階層圖層樹**選專案圖層（可捲動；含子層）。
3. **幾何類別勾選**：顯示數量；Point／Curve 預設不勾，其餘預設勾。記住上次成功勾選（同一 session；可議是否寫進設定檔）。

其後：

- 依明確物件 ID；隱藏／鎖定暫時顯示解鎖；**禁止 `_SelAll`**。
- 寫入 pending IFC → 驗證 → atomic 成 `models/R2M.ifc`；失敗不碰 last-good。
- 來源文件狀態還原（含 `doc.Modified`）。
- 空範圍／取消任一步＝阻擋，不發布。

BIM：第一次連結該 IFC。之後 Rhino 覆寫同一檔時，依各軟體「重新載入連結」操作（寫進日後使用說明；本輪不實機）。

## Inbound

1. BIM 只出 **3D 管線**（衝突段或勾選系統；不要整棟、不要 2D）。含保溫／外包絡為佳。
2. 檔放到設定根 `inbound/`（或指令選檔；可議）。
3. `RMInbound` 讀 IFC，只收 MEP 相關類（篩選規則可議），建成鎖定參考圖層（候選 `R2M::Ref`）。
4. 再跑一次＝整批換成新參考，舊參考清掉或標過期（可議）。
5. **不**布林建築、不寫 UserText 當 Dictionary、不進出圖。

人看著參考改原天花／牆／板，再跑 Models。

## 失敗停點

| 情況 | 行為 |
|---|---|
| 未存檔 | 停止 |
| 空圖層／沒勾類別／取消 | 不發布 |
| IFC 寫入或驗證失敗 | 保留 last-good |
| 進來的檔沒有可辨識管線幾何 | 停止並說明 |
| 無法載入 IfcOpenShell（日後） | 停止並說明，不裝 VisualARQ 當默認後門（除非決策改口） |
