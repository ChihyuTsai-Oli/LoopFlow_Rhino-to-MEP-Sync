# Changelog

## [1.0.5] - 2026-11-10

Toolbar buttons now have dedicated light and dark SVG artwork for Rhino 8 themes. Do not overwrite `v1.0.4`. Quit Rhino completely after install.

## [1.0.4] - 2026-10-12

Toolbar button names are **R2M Open**, **R2M Storey**, **R2M Models**, and **R2M Inbound**. Do not overwrite `v1.0.3`.

## [1.0.3] - 2026-10-12

The toolbar group in Rhino's toolbar list is **LoopFlow R2M**, the same name as the tab. The plug-in checkbox uses that name too. Do not overwrite `v1.0.2`.

## [1.0.2] - 2026-10-12

The Rhino tab **LoopFlow R2M** is included again and opens on install. **LoopFlow R2X** stays an optional extra toolbar. Do not overwrite `v1.0.1`.

## [1.0.1] - 2026-10-12

This package no longer opens its own Rhino tab. Use the shared **LoopFlow R2X** tab from `loopflow-R2X-Toolbar`. A tab already loaded in Rhino stays until you close it. Do not overwrite `v1.0.0`.
